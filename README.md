# Sports Manager
**Version:** V2.0.0

## About the Project
Welcome to Sports Manager! Developed by IEU students as a CE 216 course project, this desktop simulation game is designed to make you feel like a real manager for your team and challenge your strategic skills. Lead your team to the championship, manage your squad, and make critical decisions on match days.

## Key Features
* **Multi-Sport Leagues:** Start a custom league by choosing between Football and Handball.
* **Deep Team Management:** Set your starting lineup, manage substitutes, monitor injury statuses, and choose your active tactic (e.g., 4-4-2, 3-5-2).
* **Interactive Match Days:** Follow real-time match events (goals, cards, injuries) chronologically.
* **Dynamic Half-Time Controls:** Adapt your strategy mid-game by making live player substitutions and tactic changes during the half-time break.
* **Comprehensive Tracking:** Monitor the entire league's fixtures, match events, and season standings in detail.
* **Save & Load:** Save your progress at any time and continue your game later from the main menu.

## How to Run
You can run the game using any of the following methods:

* **Run via Batch File (Quickest):** Simply double-click the `setup.bat` file included in the source code directory.
* **Run via IDE:** Execute `src/main/java/sportsmanager/Main.java` in your preferred IDE.
* **Run via Maven:** Use the command `mvn exec:java` or `mvn clean javafx:run` in your terminal.
